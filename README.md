# IFinance

A personal finance management application built with JavaFX and MySQL.

---

## 🛠️ Prerequisites & Requirements
To run this project on your local machine, ensure you have the following installed:

* **IDE:** IntelliJ IDEA
* **JDK:** Minimum Version `17.0`
* **JavaFX:** Minimum Version `21`
* **Database:** MySQL
